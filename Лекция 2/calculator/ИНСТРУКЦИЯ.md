# Задачи 1–4: настройка рабочего места

Открой терминал в этой папке calculator. Команды ниже для Windows.

## Задача 1 — окружение, NumPy, тестовый скрипт
```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```
Активация не обязательна: здесь явно используется Python из окружения.
Для macOS/Linux замени `.venv\Scripts\python.exe` на `.venv/bin/python`.
Проверить установку: `.venv\Scripts\python.exe -c "import numpy; print(numpy.__version__)"`.

## Задача 2 — Git и GitHub
Создай пустой репозиторий calculator на GitHub без README.
В последней команде с URL подставь адрес своего репозитория.
```bash
git init
git add .
git commit -m "Initial calculator project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/calculator.git
git push -u origin main
```
Если Git запросит имя и почту, настрой их через `git config user.name`
и `git config user.email`. Для push потребуется авторизация на GitHub.
Эти команды нужно выполнить на своём компьютере: архив не создаёт
окружение и не публикует репозиторий автоматически.

## Задача 4 — поиск ошибки с отладчиком
В лекции `return a / b` вызывает ZeroDivisionError при b = 0.
Исправление в divide(): проверить делитель до деления; вернуть None
при нуле. Основная программа выводит понятное сообщение.
Чтобы посмотреть исправленный код пошагово:
```bash
python -m pdb calculator.py
```
Введи `b divide`, затем `c`. В качестве чисел введи 10 и 0.
Когда отладчик остановится внутри divide, введи `p second_number`:
получишь 0. Команда `n` выполняет следующую строку; `c` продолжает
выполнение, `q` завершает отладку. Теперь деление на ноль не выполняется.
