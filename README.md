# Решения по Яндекс Практикуму

Репозиторий для хранения решений учебных заданий по Python из Яндекс Практикума.

Решения разложены по папкам соответствующих лекций:

- `Лекция 1` — основы Python.
- `Лекция 2` — функции и проект калькулятора.
- `Лекция 3` — объектно-ориентированное программирование.

Репозиторий пополняется по мере прохождения курса.
