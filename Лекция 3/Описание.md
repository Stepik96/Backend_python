# Лекция 3 — объектно-ориентированное программирование

1. `01_books.py` — задачи 1–4: `Book`, `Ebook`, `info()`, `__str__`,
   `__eq__`, свойство возраста с сеттером, создание из строки,
   абстрактный `Printable` и реализация `print_info()`.
2. `02_employees.py` — практика 1: `Employee`, `Manager`, `Developer`.
   Оклад сотрудника; премия менеджера за каждого подчинённого;
   оплата переработок разработчика.
3. `03_vehicles.py` — практика 2: `Vehicle`, `Car`, `Bicycle`, `Boat`.
   Общий метод `description()` с разным поведением.
4. `04_online_shop.py` — практика 3: `Product`, `Order`, `Customer`,
   `ShoppingCart`. Управление корзиной, проверка и списание остатков,
   скидка и налог, история заказов. Налог начисляется после скидки.
5. `05_spaceship.py` — практика 4: `SpaceShip`, `CrewMember`, `Mission`.
   Топливо, корпус, скорость, экипаж, цели, ресурсы и события.
   В демонстрации события идут в фиксированном порядке.

Каждый файл запускается отдельно командой `python имя_файла.py`
и содержит пример использования классов. Дополнительные библиотеки не нужны.
